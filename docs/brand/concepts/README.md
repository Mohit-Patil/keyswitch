# KeySwitch logo concepts

These full-resolution raster masters were generated on 2026-08-07 as visual
directions for the KeySwitch identity. The dark Codex Micro-style HUD was used
only as a material and color reference.

| Concept | File | Direction |
| --- | --- | --- |
| A | `keyswitch-logo-a-key-switch.png` | Abstract K, keyboard layers, toggle, and six agent lights |
| B | `keyswitch-logo-b-agent-matrix.png` | Six agent states divided by a switching layer |
| C | `keyswitch-logo-c-layered-switch.png` | Minimal overlapping layers with a central status light |

These are exploration assets, not shipping app icons. After a direction is
selected, recreate its core geometry as a deterministic vector master, test it
at 16 px and in monochrome, and export the complete macOS AppIcon set. Keep the
generated raster as visual provenance rather than using it as the source of
truth for future icon sizes.
