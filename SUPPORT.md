# Support

KeySwitch is an experimental, community-supported project.

## Questions and ideas

Use [GitHub Discussions](https://github.com/Mohit-Patil/keyswitch/discussions)
for setup help, usage questions, mapping ideas, and general design discussion.

## Bugs

Use the structured
[bug report form](https://github.com/Mohit-Patil/keyswitch/issues/new/choose)
for reproducible defects. Include macOS, KeySwitch, and Codex versions when
relevant. Sanitize screenshots and logs before attaching them.

## Security

Do not use Discussions or Issues for vulnerabilities. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md).

## Scope

The maintainers cannot provide official support for Codex, macOS, or third-party
hardware. Undocumented Codex integration may temporarily stop working after an
upstream update.
