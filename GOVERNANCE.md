# Governance

KeySwitch is maintained by Mohit Patil with help from project contributors.

## Decision making

Routine fixes and small improvements are decided through pull-request review.
Larger product, security, architecture, or compatibility changes should begin
with a public Discussion or issue. The maintainer seeks rough consensus and is
responsible for the final decision when consensus is not possible.

Decisions should favor keyboard safety, user privacy, accessibility, simple
maintenance, and graceful failure when upstream Codex behavior changes.

## Maintainer responsibilities

Maintainers are expected to:

- enforce the Code of Conduct consistently;
- review contributions respectfully and in a reasonable time;
- protect private vulnerability and conduct reports;
- keep releases, documentation, and security guidance accurate; and
- disclose conflicts of interest that affect a project decision.

## Becoming a maintainer

Contributors who demonstrate sustained, constructive work and sound judgment
may be invited to help triage issues or review changes. Additional access is
granted gradually and can be removed when responsibilities are inactive or the
Code of Conduct is violated.
